# Documents

## Your resume

Put your resume in this folder with exactly this filename:

```
resume.pdf
```

The full path is `public/documents/resume.pdf`.

To update it later, replace that file with a newer PDF of the same name. You do
not need to change any code: the "Resume" links in the navigation bar, the home
page, and the footer all point at this one path.

**The resume links only appear once the file exists.** Until you add
`resume.pdf`, the site simply leaves those links out rather than showing a
broken download.

This README file is ignored by the website.
